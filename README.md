# 🛒 E-Commerce Web Application

A full-stack e-commerce web application developed to simulate a real-world online shopping experience. 
The project focuses on responsive frontend design, dynamic client–server interaction, and secure backend functionality using modern web development practices.

🚀 Features

User authentication system (Sign up, Login, Logout)
Dynamic product listing with category filtering, sorting, and pagination
Product detail pages with image gallery and interactive UI
Shopping cart functionality (add, remove, update quantity)
Real-time order summary with tax and shipping calculations
Secure checkout flow
Responsive and mobile-friendly user interface
Reusable UI components (header, footer)
REST-style backend APIs for seamless data communication

🛠 Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6)
Backend: PHP (REST-style APIs, session management)
Database: MySQL
Tools & Platforms: Git & GitHub, Postman, Browser Developer Tools

📂 Project Overview

Frontend handles UI rendering, validations, and dynamic updates using JavaScript
Backend manages authentication, products, cart, and order data using PHP
MySQL database stores users, products, and cart information
Clean separation between frontend and backend logic for maintainability

Improved skills in responsive UI/UX design
